公网发布、更换背景与写作指南

一、如何让更换的背景图、配色与新文章对所有访客生效？

1. 点击右上角「设置 / 背景」打开工作台，上传你的背景图（可一键转黑白、调节模糊度与遮罩深浅、为首页/诗歌/科研分别设置），或修改个人信息、导入 .md 文章。
2. 调整满意后，点击工作台底部的 「↓ 导出包含当前背景与文章的完整网页 (index.html)」。
3. 将下载得到的 index.html 部署到 Vercel 或 GitHub Pages，任何访客打开你的网址，看到的都是你设定好的背景与内容。

二、如何免费发布到公网？

• 方案 A（Vercel 极速部署）：注册并登录 Vercel，新建项目或将含 index.html 的 GitHub 仓库导入，无需配置构建命令（Framework Preset 选 Other），点击 Deploy，30 秒即可获得全球加速的 https://你的名字.vercel.app 链接。
• 方案 B（GitHub Pages 永久托管）：在 GitHub 新建名为 用户名.github.io 的公开仓库，上传 index.html，在 Settings → Pages 中开启部署，即可通过 https://用户名.github.io 访问。
